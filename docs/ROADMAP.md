# Roadmap

## MVP

- Vue + Vite chat UI.
- Fastify TypeScript backend.
- File-based context ingestion from `context/`.
- Editable in-session personality prompt.
- Browser voice selection and speech synthesis.
- Browser speech recognition when supported.
- Optional web search toggle routed through a backend adapter.
- Development fallback provider when no AI key is configured.

## Next Candidates

- Persist named personalities.
- Persist chat history.
- Add context upload and document management UI.
- Add provider settings UI.
- Add OpenAI web search citations in the chat UI.
- Add API-based speech-to-text and text-to-speech.
- Add Prisma + SQLite persistence.

## Later

- User accounts and cookie/session auth.
- PostgreSQL production storage.
- Context indexing and semantic retrieval.
- Role-based sharing for personalities and context collections.
- Import/export of context packs and personality profiles.
